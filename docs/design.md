# 卫戍协议（Stronghold Protocol）· iOS 原生客户端 — 设计稿 design.md

状态：v1.0（2026-10-05，Colo）。对应 brief v1.1（路线二：纯原生重写）。
文案：逐字采用 Camo 定稿 stronghold-copy.md（含资源管理屏版本）；术语统一「部署 / 连接 / 同盟模拟 / 独立模拟 / 房间密钥 / 干员 / 招募 / 摆阵 / 回合 / 结算」。
视觉基准：对部署站点 https://stronghold.lunar.ag 实测截图（登录、模式选择、房间、战前信息、策略轮选、休整期、作战、离开确认）。

## 1. 气质（Mood）

「罗德岛作战终端」：低亮度深绿黑底、薄荷绿战术强调、琥珀金作资源色、细线框 + 角标括弧 + 等宽英文小标签。信息密度高但层级清晰；一切强调色都有语义（绿=可交互/确认，金=资源/选中，红=敌方/危险，蓝=友方出生/冰冻，橙=计时警告）。

一句话：**黑色玻璃上的作战地图，绿色是唯一的「你能动手」的信号。**

## 4. 形状、间距、图标

- 圆角：按钮/输入 0pt（直角，对齐原版的硬边战术感）；卡片 0pt 直角 + 1px 边框；弹窗 8pt；徽章用六边形（价格、等阶）与方形（禁用标签）。
- 间距基尺：4pt 网格。屏边距 16pt（iPhone）/ 24pt（iPad）；卡片内边距 12pt；组件间距 12pt；分组间距 24pt。
- 边框：常态 1px `mintDim` 或 #2A352E（中性）；选中 1.5px 语义色 + 四角 12pt 角标括弧（2px 线宽），括弧是「可交互/已选中」的统一记号。
- 主按钮：mint 填充、深色文字 #0B100D、右端 45° 斜纹饰带（宽 24pt，透明度 25%），高度 44pt（屏内）/ 52pt（全宽 CTA）。
- 触控最小 44×44pt；棋盘格点击热区每格 ≥ 52pt。
- 图标：一律 SF Symbols，不用位图图标。映射：返回 `chevron.left`；添加部署 `plus.square.on.square`；删除 `trash`；编辑 `pencil`；刷新（商店）`arrow.counterclockwise`；冻结 `snowflake`；升级 `arrow.up.square`；资金 `scope`（六边形瞄准镜，代表调度资金，金色）；暂停 `pause.fill`；设置 `gearshape`；玩法说明 `book`；全屏 `arrow.up.left.and.arrow.down.right`；表情 `face.smiling`；倒计时 `timer`；信号 `antenna.radiowaves.left.and.right`；下载 `arrow.down.circle`；导入 `square.and.arrow.down`；导出/ZIP `doc.zipper`；Wi-Fi 限定 `wifi`；清除 `clear`。

## 5. 组件库（SwiftUI 命名直接可用）

1. `TacPanel` — bg/panel + 1px 边框 + 顶部左侧等宽英文小标签（如 `SIMULATION MODE`）+ 中文标题；右上角可挂动作。
2. `BracketFrame` — 选中态括弧框（参数：色、线宽 2、臂长 12）。
3. `PrimaryButton(text:)` — mint 填充 + 斜纹饰带 + 深色文字；禁用时 30% 透明度灰绿。
4. `GhostButton` — 透明底 + 1px mintDim 边框 + mint 文字（次要操作：编辑/冻结/暂停）。
5. `DangerButton` — 1px red 边框红字，填充态仅用于「放弃模拟」级不可逆操作。
6. `DoubleTapConfirm` — 两次点选确认模式：第一次点选变亮 + 文案变「再点一次确认」，2.5 秒无第二击自动回落。招募、升级、机变选卡、清缓存一律使用。
7. `HexBadge(value:)` — 六边形徽章，金底深字=价格；黑底金字=等阶 I/II/III；绿底=层数。
8. `MonoLabel(en:)` — 等宽英文小标签。
9. `StatusChip` — 顶栏胶囊：延迟（≤80 mint / ≤200 白 / >200 amber）、回合数、HP。
10. `Banner(system:)` — 顶部插入式横幅（重连中=amber 边框呼吸动画；成功=mint 一闪 2s 撤出）。
11. `WheelDirection` — 方向轮盘组件（见 S7）。

## 6. 导航结构

```
连接（Tab 根，列表 + 添加）
 └─ 登录/注册（部署带账号体系时）
 └─ 下载资源（首次/缺资源时拦截页，可跳过进入按需模式）
 └─ 大厅（=原版「选择模拟协议」屏）
     ├─ 独立模拟 → 难度选择（同屏分段控件）→ 战前：本局信息 → 策略轮选 → 对局
     ├─ 同盟模拟 → 房间（座位/密钥/AI 补位/难度）→ 战前两步 → 对局
     └─ 输入 4 位房间密钥加入 → 房间
对局内（全屏，无导航栏）：
  休整期 ⇄ 作战 循环（顶栏回合计数）→ 第 14 回合后 最终攻势 → 结算
全局浮层：设置（对局内外皆可开）、资源管理、玩法说明、干员调配、长按详情、离开确认
```

- 屏级返回一律左上 `chevron.left`+「返回」；对局内离开走红色方钮 + 确认弹窗（对齐原版：放弃模拟文案）。
- iPhone：对局仅横屏；非对局屏竖横皆可但按横屏优先设计。竖屏进入对局时显示全屏提示「请横持手机以获得最佳视野」+ 旋转图标 `rotate.landscape`，检测到横屏即淡出。iPad 全横竖自由。
- 深链：`stronghold://join/KEY` 与 https 链接 `?room=KEY` 都能进房（Universal Links）。

## 7. 屏幕规格（逐屏）

### S1 连接（根屏）
- 结构：顶部大标题「连接」+ 标语「口袋里的协议战棋」（首启时）；部署列表（每条：名称=部署地址域名、上次连接时间、状态点：mint=健康 / amber=检查中 / red=失败，右侧 `chevron.right`）；底部固定主按钮「添加部署」。
- 空态（文案照 copy.md）：居中六边形瞄准镜轮廓图标（mint 30%）、标题「还没有连接任何部署」、正文「添加一个部署地址，即可开始游玩。」、按钮「添加部署」。
- 添加/编辑：模态表单，字段=部署地址（占位「输入部署地址（如 https://stronghold.lunar.ag）」），键盘 URL 型，自动补 https:// 前缀；保存即触发健康检查，状态行显示「检查部署状态…」→ 成功打绿点 + 「已连接服务器 · v0.1.2」，失败「无法连接该部署。请检查地址和网络。」+「重试」。
- 操作：左滑删除（红色，需 DoubleTapConfirm 确认「删除后不保留该部署的登录信息」）、点击行=「连接」主操作，连接中按钮文案「正在连接…」。
- 错误态：WebSocket 握手失败/版本不匹配时给出三条内联说明（地址不可达 / 部署版本过旧，需 v0.1.2+ / 网络不可用），各带「重试」。

### S2 登录（部署启用账号时；复用部署账号，App 不自建账号）
- 结构：居中窄卡（宽 360pt）：分段控件「登录 / 注册」；登录=用户名+密码；注册=用户名+博士代号+密码+确认密码；主按钮「登录/注册」；下方 Ghost 按钮「使用 GitHub 登录」（走 ASWebAuthenticationSession）；底行三个入口：资源管理、玩法说明、退出登录（已登录时）。
- 校验失败在字段下红字内联提示；密码用 `SecureField`，可切换明文。
- 说明：此屏 copy.md 未覆盖，我按原版字段与统一术语补位（用户名/密码/博士代号/使用 GitHub 登录），请 Camo 过目定稿。
- 已登录态：昵称徽章「博士代号#编号」常驻大厅顶栏右侧，点开=修改代号/修改密码/退出登录菜单。
- （开发者注 Pluso：账号体系走 Workers 部署的独立通道 worker/room-net.js，协议与普通 ws 会话不同，排在普通流程跑通之后。）

### S3 资源管理（M1 重点，四条路径完整）
- 结构：顶部总览卡：环形进度（mint，中心百分比）+ 总体状态文案（「尚未下载资源」/「已下载 x%，可继续下载」/「资源已就绪」）+ 已用空间统计 + 末次校验时间。
- 主操作区：全宽 PrimaryButton「全部下载」；下载中变「暂停」（Ghost）+ 继续按钮；断点续传时顶部 Banner「上次下载未完成，已从断点继续。」。
- 分组清单（照 copy.md 五组：干员立绘 / 立绘语音 / 音效 / 战斗音频 / 其他）：每组行=组名 + 「已下载 x / 共 y」+ 线性进度条（mint，剩余部分 mintDim）+ 组内「下载本组」Ghost 按钮；组展开可看单文件（图标缩略、大小、状态勾/箭头/叹号）。
- 右上角菜单：「下载完整包（ZIP）」（副文案「适合一次性拉取全部资源」，触发系统下载，完成后自动解包入库并校验）、「导入 ZIP 文件」（`fileImporter`，导入中遮罩「正在校验导入的资源…」，成功 toast「导入完成」，失败「该文件无法识别或已损坏」+「重试」）、「清除已下载资源」（DoubleTapConfirm 弹窗「确定清除吗？清除后需重新下载。」）。
- 设置项：仅 Wi-Fi 下载开关（蜂窝时 amber 提示条「当前使用蜂窝网络，已暂停下载」+「仍要下载」）、后台下载说明行。
- 失败态：组行变红叹号 + 全局 Banner「下载失败，请检查网络后重试。」+「重试」；断网时清单只读可浏览。
- 版本提示：检测到部署素材版本变化 → 顶部 amber Banner「部署资源已更新，需补齐 x 项。」+「去补齐」。

### S4 大厅（=原版「选择模拟协议」）
- 结构：顶栏=返回 + 屏题「选择模拟协议」+ 工具组（玩法说明 / 资源管理 / 干员调配）+ 玩家徽章（首字母块 + 博士代号#编号 + DOCTOR）。
- 三列布局（iPad）/纵向分区（iPhone 横屏，两栏网格）：
  - 01 模拟方式：两张大卡（独立模拟 / 同盟模拟），六边形人形图标（SF `person.fill`/`person.2.fill` 收进六边形），选中=mint 边框 + 括弧 + 「已选定」角标；
  - 02 模拟难度：四行横条（标准/险境/绝境/终极 + AC-n 编号 + 回合数 + 特性要点 + 战场信息），选中=amber 边框 + 金色✓徽章「已选定」；险境以上红色标题 + 红色「+ 隐秘核心」小签；
  - 03 加入同盟：4 位密钥输入（4 格分离输入框，每格 1 字符，自动跳格，粘贴自动分段）+「加入同盟」按钮（未满 4 位禁用）。
  - 底部主按钮随模式切换：「创建同盟」（同盟）/「开始独立模拟」（独立）。
  - 侧栏：在线大厅（公开对局列表，空态「当前没有有真人在线的公开大厅」+ 刷新）、作战提示轮播（21 条，左右翻页箭头）。
- 对局记录/个人统计：顶栏下行 Ghost 按钮组，进入部署自带的记录页（原生列表：时间、难度、结果、称号）。

### S5 房间（同盟模拟）
- 结构：顶栏（离开=红方钮「离开同盟」+ 延迟 StatusChip + 屏题「独立/同盟模拟」+ 玩法说明/资源管理）。
- 主区：座位卡横排 4 位（P1–P4）：头像块、座位号 `SEAT 01`、身份「创建者/你」、状态（待命中=灰 / 决策中=amber / 已准备=mint）、AI 队友卡带 `cpu` 图标与「移除」角标；空位虚线框 +「+ 添加 AI 队友」。
- 右侧 Briefing 面板：难度名 + 特性列表 + 回合数。
- 房主专属：底部难度radiogroup（四档，同 S4 语义色）+「开始模拟」PrimaryButton（非房主见「等待房主开始」+ 灰按钮）；全员准备后按钮呼吸动画。
- 密钥分享：顶部居中「房间密钥 XXXX」大字（SF Mono 28pt，字符间距 +4）+ 复制按钮 `doc.on.doc` + 分享 `square.and.arrow.up`（分享文案含深链）。
- 空态（非房主等待）：「等待队友加入…」+「把房间密钥分享给朋友，即可一起作战。」+ 密钥重显。

### S6 战前两步（对局内横幅式，非独立页）
- 步 1/2 本局信息：顶栏「1 / 2 确认本局信息」；主区左=敌方领袖卡（领袖名、登场回合、特性三条、`skull` 图标）+ 战场卡（战场编号、特训敌人三行）；右=盟约面板（核心盟约六边形 chips + 附加盟约 chips，灰色=阵容不完整，右上数字=层数上限提示）+ 本局禁用干员（头像行，灰化）。
- 底栏：「干员调配」Ghost + 「已就绪 0/1」+「准备就绪」PrimaryButton。
- 步 2/2 策略轮选：顶栏「2 / 2 选择策略」（数字 2 用 mint 40pt 强调）；左列=玩家决策卡（金框「决策中」）；中=策略卡网格（40 张，3–5 列自适应：头像、名称、金徽章费用；禁用卡灰化 + 虚线「本局禁用」签）；右=详情面板（大头像、初始生命值大数字、`EFFECT` 等宽标签 + 效果名 mint + 描述、底部「确认选择」PrimaryButton）。
- 同盟模式：其余席位头像列在左列下方，状态实时（决策中/已决定✓）。

### S7 休整期（对局核心屏）
- 布局（横屏）：
  - 顶栏（高 52pt，bg/base + 1px 底边）：左=离开红方钮 + 延迟 chip + 难度名；中=本局信息按钮 + 「回合 n」白块 + 阶段胶囊「休息一下」（mint 边框，作战时变「作战中」amber）+ 资金徽章（`scope` 金 + 数字）+ 展开按钮；右=「准备就绪」Ghost 按钮（独立模拟显示 Space 角标改「随时可继续」；同盟显示倒计时环）。
  - 左上：BONDS 提示条（未激活时「部署干员以激活盟约」；激活后 chips 点亮）。
  - 左中：同盟成员栏（头像、资金、状态；观战入口=点队友头像→「前往查看」）。
  - 右缘：EFFECTS 生效效果栏（图标纵列，点击出说明）。
  - 中央：棋盘。整盘等比缩放至可用区最大内接尺寸，格间 1px 缝；红门格 danger/door 辉光、蓝门 ally/blue、地形装置用 SF Symbols 覆盖（阻隔工事 `shield.lefthalf.filled`、射击台 `scope`、源石流吹风机 `wind`、沼泽 `drop`、排气格栅 `fanblades`、涨潮 `water.waves`）。
  - 整备区：棋盘下方一行虚线金框槽位（10 格），已招募干员立绘缩略 + 等阶徽章；装备/法术槽在右端分组。
  - 底部右：调度中心面板（高 120pt）：剩余可放置数、冻结（frost 蓝 Ghost）、刷新（Ghost + 金徽章费用）、LEVEL 升级卡（费用徽章 + `arrow.up.square`）、4 张商品卡 + 资金余额；「收起」可折叠成一条 64pt 头部条。
  - 左下：交流（表情）、设置、玩法说明、全屏（Ghost 方钮）。

## 8. 无障碍
- 所有可点组件 `accessibilityLabel` 用 Camo 术语（如商品卡=「招募艾丝黛尔，费用 2，萨尔贡，强攻手」）。
- 轮盘替换交互：拖拽不可用（VoiceOver）时提供等价路径——点选干员→详情面板内「选择朝向」四向按钮组。
- 颜色从不单独承载语义：选中=边框+括弧+角标文字；禁用=灰化+禁用文案；红/绿数值同时带 +/- 符号。
- 对局内 HUD 固定字号（锁 Dynamic Type，破版风险），屏外页面全量支持；`UIAccessibility.isReduceMotionEnabled` 时关掉呼吸/辉光动画，轮盘改为点选四向。
- 最低对比度已在色板保证；红门辉光叠加不承载信息（另有格子图标）。
