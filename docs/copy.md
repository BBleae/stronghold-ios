# copy.md — 用户文案定稿（2026-10-05，含登录屏与资源管理屏）

App 名称：**卫戍协议（Stronghold Protocol）**
Bundle ID 后缀 / 子域名：`stronghold`（stronghold.apps.air.build）
标语（可用于网站/商店副标题）：口袋里的协议战棋

## 统一术语（全 App 一律用这些词，不混用同义词）
| 概念 | 统一用词 | 不用 |
|---|---|---|
| 所连接的服务器 | 部署 | 服务器、主机、节点 |
| 新建/保存的部署条目 | 连接 | 服务器条目、配置 |
| 联机合作对局 | 同盟模拟 | 多人模式、合作 |
| 单人对局 | 独立模拟 | 单机、单人模式 |
| 加入对局的口令 | 房间密钥 | 密码、邀请码 |
| 可操作角色 | 干员 | 单位、棋子 |
| 选取干员上场 | 招募 | 选人、购买 |
| 放置干员到格子 | 摆阵 | 部署、放置 |
| 一局中的阶段 | 回合 | 波次、关卡 |
| 战斗结束画面 | 结算 | 战报、成绩 |

## 屏序：连接 → 登录 → 大厅 → 对局 → 资源下载 → 设置 → 结算 → 资源管理

### 屏 1：连接（连接管理页）
- 屏幕标题：连接
- 主操作按钮：连接
- 次要操作：添加部署、编辑、删除
- 输入框占位符：输入部署地址（如 https://stronghold.lunar.ag）
- 连接中：正在连接…
- 连接失败：无法连接该部署。请检查地址和网络。
- 健康检查文案：检查部署状态…

### 空状态：尚无部署
标题：还没有连接任何部署
正文：添加一个部署地址，即可开始游玩。
按钮：添加部署

### 屏 2：登录（部署启用账号体系时；App 不自建账号，复用部署账号）
- 屏幕标题：登录（分段控件：登录 / 注册）
- 主操作按钮：登录（注册页签下按钮文案：注册）
- 字段：
  - 用户名（占位符：用户名）
  - 密码（占位符：密码；可切换明文：显示密码 / 隐藏密码）
  - 博士代号（占位符：博士代号；辅助说明：博士代号是其他玩家看到的名字，形如 博士#1234）
  - 确认密码（占位符：确认密码）
- 次要操作：使用 GitHub 登录
- 登录失败：用户名或密码错误。
- 注册失败（用户名已占用）：该用户名已被使用。
- 两次密码不一致：两次输入的密码不一致。
- 字段为空：请填写完整后再继续。
- 网络/服务错误：连接部署时出错，请稍后重试。
- 已登录态徽章：博士代号#编号；点开菜单：修改博士代号 / 修改密码 / 退出登录
- 退出登录确认：确定退出登录吗？（确认按钮：退出登录）

### 屏 3：大厅（=原版「选择模拟协议」屏）
- 屏幕标题：选择模拟协议（与原版一致）
- 主操作：独立模拟
- 次要操作：同盟模拟
- 加入房间输入框占位符：输入 4 位房间密钥
- 昵称输入框占位符：输入你的昵称

### 空状态：正在等待队友
标题：等待队友加入…
正文：把房间密钥分享给朋友，即可一起作战。

### 屏 4：游戏（对局内）
- 横屏提示（iPhone 竖屏时显示）：请横持手机以获得最佳视野
- 重连横幅：连接已断开，正在重连…
- 重连成功：已重新连接
- 重连失败（超 10 分钟）：连接超时，无法回到对局。

### 屏 5：资源下载（首次/缺资源时拦截页，可跳过进入按需模式）
- 屏幕标题：下载资源
- 主操作：开始下载
- 进度文案：正在下载资源…（已下载 x%）
- 下载失败：下载失败，请重试。
- 完成提示：资源就绪，可以开始游戏了。

### 屏 6：设置
- 屏幕标题：设置
- 画质选项：高 / 中 / 低
- 音量滑块：音量（含音效 / 语音 / 音乐三分滑块，对齐原版设置能力）
- 深色外观：始终使用深色外观（不随系统切换）
- 清除资源缓存：清除已下载资源

### 屏 7：结算
- 屏幕标题：结算
- 主操作：再来一局
- 次要操作：返回大厅

### 屏 8：资源管理（原网页端同功能，完整实现）
- 屏幕标题：资源管理
- 总体状态文案：
  - 未下载：尚未下载资源
  - 部分下载：已下载 x%，可继续下载
  - 全部完成：资源已就绪
- 清单条目文案：分组名（干员立绘 / 立绘语音 / 音效 / 战斗音频 / 其他），每组显示：已下载 x / 共 y
- 主操作：全部下载
- 次要操作：暂停、继续
- 续传提示：上次下载未完成，已从断点继续。
- 下载失败：下载失败，请检查网络后重试。（按钮：重试）
- 完整资源包：下载完整包（ZIP）｜提示：适合一次性拉取全部资源。
- 本地导入：导入 ZIP 文件｜导入中：正在校验导入的资源…｜导入成功：导入完成｜导入失败：该文件无法识别或已损坏。
- 清除：清除已下载资源（确认弹窗：确定清除吗？清除后需重新下载。）
