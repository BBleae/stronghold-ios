# copy.md — 用户文案定稿（含资源管理屏，2026-10-05）

App 名称：**卫戍协议（Stronghold Protocol）**
Bundle ID 后缀 / 子域名：`stronghold`（stronghold.apps.air.build）
标语（可用于网站/商店副标题）：口袋里的协议战棋

## 统一术语（全 App 一律用这些词，不混用同义词）
| 概念 | 统一用词 | 不用 |
|---|---|---|
| 所连接的服务器 | 部署 | 服务器、主机、节点 |
| 新建/保存的部署条目 | 连接 | 服务器条目、配置 |
| 联机合作对局 | 同盟模拟 | 多人模式、合作 |
| 单人对局 | 独立模拟 | 单机、单人模式 |

| 选取干员上场 | 招募 | 选人、购买 |

## 界面文案

### 屏 1：连接（连接管理页）
- 屏幕标题：连接
- 主操作按钮：连接
- 次要操作：添加部署、编辑、删除
- 输入框占位符：输入部署地址（如 https://stronghold.lunar.ag）
- 连接中：正在连接…
- 连接失败：无法连接该部署。请检查地址和网络。
- 健康检查文案：检查部署状态…

### 空状态：尚无部署
标题：还没有连接任何部署
正文：添加一个部署地址，即可开始游玩。
按钮：添加部署

### 屏 2：大厅（进入部署后）
- 屏幕标题：大厅
- 主操作：独立模拟
- 次要操作：同盟模拟
- 加入房间输入框占位符：输入 4 位房间密钥
- 昵称输入框占位符：输入你的昵称

### 空状态：正在等待队友
标题：等待队友加入…
正文：把房间密钥分享给朋友，即可一起作战。

### 屏 3：游戏（对局内）
- 横屏提示（iPhone 竖屏时显示）：请横持手机以获得最佳视野
- 重连横幅：连接已断开，正在重连…
- 重连成功：已重新连接
- 重连失败（超 10 分钟）：连接超时，无法回到对局。

### 屏 4：资源下载（首次进入）
- 屏幕标题：下载资源
- 主操作：开始下载
- 进度文案：正在下载资源…（已下载 x%）
- 下载失败：下载失败，请重试。
- 完成提示：资源就绪，可以开始游戏了。

### 屏 4b：资源管理（完整复刻，M1）
- 清单按组显示已下载进度
- 全部下载 / 暂停 / 继续，断点续传提示
- 完整资源包 ZIP 下载；本地 ZIP 导入（校验失败提示）

### 屏 5：设置
- 屏幕标题：设置
- 画质选项：高 / 中 / 低
- 音量滑块：音量
- 深色模式：跟随系统（默认，无单独开关文案需要）
- 清除资源缓存：清除已下载资源

### 屏 6：结算
- 屏幕标题：结算
- 主操作：再来一局
- 次要操作：返回大厅
