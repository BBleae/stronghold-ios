# 卫戍协议（Stronghold Protocol）· iOS 原生客户端 — 产品方案（brief v1.1）

状态：v1.1 定稿（2026-10-05，Ato）。用户已拍板：**路线二 纯原生重写**；交付**本机安装 + TestFlight 内测**两者都要；**App 名「卫戍协议（Stronghold Protocol）」**（后缀 `stronghold`）；**网页端「资源管理」功能完整复刻进 App**。

## 项目是什么

原项目：https://github.com/BBleae/Stronghold-Protocol （sganggs/Stronghold-Protocol 的 fork）
《明日方舟》「卫戍协议：盟约」的非官方同人复刻：自走棋 + 塔防，浏览器即开即玩，
单人（独立模拟）或 1–4 人联机合作（同盟模拟，可加 AI 队友）。现有部署
https://stronghold.lunar.ag 已在线上运行。

用户需求：原生 iOS 实现，能连接这个项目的**现有部署**进行游玩，适配 iPhone/iPad。

## 原项目技术形态

- 架构：Node.js 服务器（WebSocket `/ws`）管经济与回合；**战斗在玩家自己的客户端里模拟**（`server/sim` 前后端共用 JS 代码）。部署默认客户端模拟（SP_COMBAT=client）。
- 网页客户端：PixiJS 7 + pixi-spine 渲染、Preact UI、Web Audio；官方美术/音频约 270 MB 不进仓库，由部署分发或玩家按需下载。
- 实测代码量（Pluso，2026-10-05）：战斗模拟+内容脚本 ~3.2 万行 JS（技能等战斗内容 2.4 万行）；对局经济/回合引擎 ~1.3 万行；网页 UI/渲染 ~3.5 万行；共享协议 ~1100 行；测试 ~10 万行。数据为机器生成 JSON（干员表 1.6 MB），直接复用。
- 协议：消息目录与校验在 `shared/protocol.js`；客户端状态视图 `m.public`/`m.private`；快照格式 DESIGN.md §8.4。

1. **素材版权**：明日方舟美术/音频/文本归鹰角所有，不适用 GPL；项目严禁商业化。含素材的客户端上 App Store / TestFlight 外部测试有被拒/下架风险。**对策：App 包体不含任何素材，素材全部从所连部署运行时按需下载**（风险压到最低但不为零）。

## 里程碑（路线二）

每步都连真实部署验证；每个里程碑交付可运行、可试玩的东西。

- **M0 协议与连接（~1–2 周）**：Swift 实现 `shared/protocol.js` 消息层 + WebSocket + 重连，连真实部署跑通 hello/建房/进房/准备；原生大厅/房间屏；Spine iOS 渲染方案验证；数据 JSON 直接复用验证。产出：真机连 https://stronghold.lunar.ag 进原生大厅。
- **M1 对局与休整期**：`m.public`/`m.private` 状态视图 + 休整期全部操作（招募、冻结、升级、拖拽摆阵、方向轮盘、装备法术、机变选卡、确认二次点击）；**「资源管理」完整实现**；战斗小人先用简化静态渲染兜底。
- **M2 战斗引擎移植**：3.2 万行模拟引擎逐模块 Swift 化（网格/寻路 → 单位/属性/buff → 伤害/元素 → 目标选取/弹道 → 技能内容分批 → 敌人/装置 → Boss）。**验证方式：差分测试**——本地跑原版 Node 引擎作标准答案，同种子对齐每帧快照。
- **M3 渲染打磨与交付**：Spine 小人、特效、音效/语音、表情；画质分档、iPad 适配；**Xcode 一键真机安装交付**。
- **M4 TestFlight 尝试**：隐私政策/Support 页备齐后提审（@appstore 接手），被拒则保留本机安装路线。

**Spine 渲染决策（Ato 负责，M3 前定）**：候选：官方 spine-ios（需编辑器授权，弃）、开源社区 Swift 移植、静态帧简化渲染兜底。倾向开源替代或简化渲染。

## 「资源管理」（用户点名完整复刻，M1 交付）

1. 在线下载全部素材：按 `data/assets.json` 清单逐项下载，断点续传、暂停/继续、失败重试，进度按文件与总量显示。
2. 下载完整资源包 ZIP：从部署拉整包并解包入库。
3. 导入本地 ZIP：系统文件选择器导入，校验后入库（覆盖网络下载）。
4. 按需加载：不预下载时进游戏按引用即时拉取并缓存。
5. iOS 特有：后台下载、仅 Wi-Fi 选项、已用空间统计、一键清缓存；大小/哈希校验；部署版本变化提示补齐。
6. 素材存 App 沙盒，不进包体。

验收补充：清空素材后四条路径各自能把一场完整对局所需素材补齐并正常作战；断网时已下载素材可继续玩。

## 界面与交互基准

- 全部界面简体中文，文案用 docs/copy.md 定稿；操作完全对齐原版（点选→再点确认；整备区拖到棋盘→方向轮盘；长按详情；双人确认防误触）。
- iPhone 横屏优先（竖屏给旋转提示），iPad 横竖皆可；断线 10 分钟内重连回座。
- iOS 17+，iPhone/iPad 通用。

## 验收标准（可观察）

1. 添加部署 https://stronghold.lunar.ag 后完成：昵称 → 独立模拟/同盟模拟 → 一整局 14 回合，不闪退不丢触控。
2. 战斗数值与原版网页客户端在同种子同阵容下逐帧一致（差分测试通过率达标；不一致项有书面解释）。
3. 局域网两台 iOS + 一台电脑开服，用 4 位密钥联机合作一整局；杀掉 App 后 10 分钟内重连回原座位。
4. iPhone 横屏 / iPad 横竖屏无布局错乱；拖拽部署手感与网页版一致。
5. App 包体不含明日方舟素材；断开服务器后无本地可玩副本。
6. 「资源管理」四条路径各自能把一场完整对局所需素材补齐并正常作战；断网时已下载素材可继续玩。
7. 真机从 Xcode 一键安装运行；TestFlight 提审材料齐备（通过与否如实报告）。

## 明确不做（v1）

App 自带账号体系（用部署自带的）、离线单机（二期再议）、观战画中画、键盘快捷键、任何变现。
