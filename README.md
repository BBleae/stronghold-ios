# 卫戍协议（Stronghold Protocol）· iOS 原生客户端

《明日方舟》「卫戍协议：盟约」非官方同人复刻 [Stronghold-Protocol](https://github.com/BBleae/Stronghold-Protocol) 的原生 iOS 客户端，可连接该项目的现有部署进行游玩（自托管 Node 服务器与 Cloudflare Workers 部署）。

- 状态：开发中（里程碑见项目 brief）。当前支持自托管 Node 部署的连接/建房/进房流程；Workers 账号部署与战斗模拟引擎移植在进行中。
- 纯原生实现：SwiftUI + Swift 战斗模拟引擎，App 包体不含任何游戏素材，素材在运行时从所连部署按需下载。
- iOS 17+，iPhone / iPad 通用，横屏优先。
